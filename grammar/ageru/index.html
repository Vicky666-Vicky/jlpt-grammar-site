真题年份必考内容，需掌握
考查方式语法题 / 句子理解
义项数量1 个用法

义项用法

1我或我方的人把某物给予他人

用法
表示说话人或我方的人把某物给别人，给予方向是从我方流向对方。
接续
我/我方 + は/が + 对方 + に + 物 + を + あげる。

私は友達に本をあげました。

わたしは ともだちに ほんを あげました。

我给了朋友一本书。

整体提醒

我/我方 + は/が + 对方 + に + 物 + を + あげる。
