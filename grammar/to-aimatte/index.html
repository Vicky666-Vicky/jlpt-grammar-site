～と（が）相まって／～も相まって

真题年份201807 / 202207
出现题型错误选项 / 正确选项
义项数量1 个用法

义项用法

1与……相结合、再加上……

用法
两个因素相互作用，使某种效果、状态或结果更加明显。
接续
名词 + と／も相まって。

彼の努力と才能とが相まって、大きな成功を収めた。

かれのどりょくとさいのうとがあいまって、おおきなせいこうをおさめた。

他的努力与才能相辅相成，取得了巨大成功。

整体提醒

名词1 + と + 名词2 + とが相まって；名词1 + が + 名词2 + と相まって；名词 + も相まって。
