N1 S级文法篇

ほど

真题年份201607 / 201712 / 201812 / 201907 / 202012等 8 次
出现题型错误选项*7 / 句子理解
义项数量5 个用法

义项用法

1达到……程度

用法
以前项说明后项状态所达到的程度，可表示实际程度或夸张比喻。
接续
普通形 / 名词 + ほど。

立っていられないほど疲れた。

たっていられないほどつかれた。

累得站不住了。

2没有达到……地步

用法
以「ほど〜ない」表示程度未达到前项所示标准。
接续
名词 / 普通形 + ほど〜ない。

心配するほどの病気ではない。

しんぱいするほどのびょうきではない。

还不是严重到需要担心的病。

3没有比……更……

用法
通过否定比较强调前项是同类中程度最高的对象。
接续
名词 + ほど + 形容词普通形 + 名词はない／いない。

健康ほど大切なものはない。

けんこうほどたいせつなものはない。

没有什么比健康更重要。

4大约……

用法
表示数量或时间的大致范围，语气通常比「くらい」稍正式。
接续
数量词 + ほど。

会場に三十人ほど集まった。

かいじょうにさんじゅうにんほどあつまった。

会场聚集了大约三十人。

5越……越……

用法
表示随着前项程度增加，后项程度也相应变化。
接续
动词ば形 + 动词辞书形 + ほど；形容词ば形 + 形容词 + ほど。

この本は読めば読むほど面白い。

このほんはよめばよむほどおもしろい。

这本书越读越有趣。

整体提醒

名词 / 数量词 / 普通形 + ほど；比较句用「ほど〜ない」；变化句用「〜ば〜ほど」。
