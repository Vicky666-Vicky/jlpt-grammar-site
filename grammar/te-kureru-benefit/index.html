てくれる

真题年份必考内容，需掌握
考查方式语法题 / 句子理解
义项数量1 个用法

义项用法

1别人为我做某事 / 给我做某事

用法
表示别人主动为我或我方的人做某事，重点是我方得到帮助或恩惠。
接续
别人 + が + 我方 + に + 动词て形 + くれる。

友達が宿題を手伝ってくれた。

ともだちが しゅくだいを てつだってくれた。

朋友帮我做了作业。

整体提醒

别人 + が + 我方 + に + 动词て形 + くれる。
