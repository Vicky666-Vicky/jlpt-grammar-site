まで／までに

真题年份201612 / 201812 / 202012 / 202112 / 202307等 6 次
出现题型句子理解*2 / 错误选项*4 / 排序题
义项数量3 个用法

义项用法

1持续到……

用法
表示动作或状态持续的终点，该动作通常一直延续到前项所示时间或地点。
接续
时间／场所名词 + まで。

今日は五時まで働きます。

きょうはごじまではたらきます。

今天工作到五点。

2在……之前完成

用法
表示动作完成的截止期限；动作可在截止点之前的任何时间完成。
接续
截止时间 + までに。

金曜日までにレポートを出してください。

きんようびまでにレポートをだしてください。

请在星期五之前提交报告。

3连……都……

用法
举出超出一般预想的极端对象，强调范围扩展到该对象。
接续
名词／普通形 + まで（も）。

その話は子供まで知っている。

そのはなしはこどもまでしっている。

那件事连孩子都知道。

整体提醒

时间／场所名词 + まで；截止点 + までに；名词／普通形 + まで（も）。
