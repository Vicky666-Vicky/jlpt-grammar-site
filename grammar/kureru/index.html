くれる

真题年份必考内容，需掌握
考查方式语法题 / 句子理解
义项数量1 个用法

义项用法

1别人给我方：别人主动给我或我方的人某物

用法
表示别人主动为我或我方的人给予某物，句子的受益方向是从对方流向我方。
接续
给予者 + が + 私/我方 + に + 物 + を + くれる。过去式常用「くれた / くれました」。

友達が私にプレゼントをくれた。

ともだちが わたしに プレゼントを くれた。

朋友送了我礼物。

整体提醒

给予物品时用「A が 私/我方 に 物 を くれる」。重点是看给予者不是我方，而受益者是我或我方的人。
