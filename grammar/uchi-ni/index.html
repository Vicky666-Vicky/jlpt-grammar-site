～うちに

真题年份202307
出现题型正确选项
义项数量2 个用法

义项用法

1趁着……、在……之内

用法
表示在前项状态尚未改变或适合做某事的期间内完成后项动作。
接续
动词辞书形／ない形／ている形、形容词或名词 + うちに。

温かいうちに、料理を食べてください。

あたたかいうちに、りょうりをたべてください。

请趁热吃这道菜。

2……着……就、不知不觉间……

用法
表示在持续进行前项动作或处于某状态的过程中，自然而然发生了后项变化。
接续
动词ている形 + うちに。

日本語を勉強しているうちに、友達が増えた。

にほんごをべんきょうしているうちに、ともだちがふえた。

在学习日语的过程中，朋友不知不觉变多了。

整体提醒

动词辞书形／ない形／ている形 + うちに；い形容词普通形 + うちに；な形容词词干 + な + うちに；名词 + の + うちに。
