N1 必背敬语专题

お／ご〜ください

专题性质N1 必背
考查方式语法题 / 句子理解
义项数量1 个用法

义项用法

1尊他请求：お/ご〜ください

用法
用于尊敬地请求对方做某事，动作主体是对方。
接续
お + 一类/二类动词ます形去ます；ご + 三类动词词干。句型核心是「〜ください」。特殊：请您看为「ご覧ください」；请您来/去为「お越しください」；请您来/去/在场为「おいでください」。

こちらにお名前をお書きください。

こちらに おなまえを おかきください。

请在这里写上您的姓名。

整体提醒

お + 一类/二类动词ます形去ます；ご + 三类动词词干。
