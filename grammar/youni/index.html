义项用法

1像……一样

用法
把某人或事物的状态、动作比作另一对象。
接续
名词 + の + ように；普通形 + ように。

彼は風のように走った。

かれはかぜのようにはしった。

他像风一样奔跑。

2像……那样，例如……

用法
提出具体例子或示范，说明前后内容具有相同方式或特征。
接续
名词 + の + ように；普通形 + ように。

東京のように人口の多い都市では、家賃が高い。

とうきょうのようにじんこうのおおいとしでは、やちんがたかい。

在东京这样人口众多的城市，房租很高。

3但愿……、希望……

用法
表达愿望或祈愿，常用于自己不能完全控制的结果。
接续
动词普通形 + ように。

試験に合格できますように。

しけんにごうかくできますように。

希望能通过考试。

4请……、务必……

用法
委婉传达要求、忠告、提醒或指示。
接续
动词辞书形 / ない形 + ように（してください／お願いします／言う）。

明日は遅れないようにしてください。

あしたはおくれないようにしてください。

明天请不要迟到。

整体提醒

名词 + の + ように；普通形 + ように；动词辞书形 / ない形 + ように。
