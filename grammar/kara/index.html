から

真题年份201507 / 201512 / 201607 / 201612 / 201706等 11 次
出现题型句子理解*10 / 错误选项*8 / 正确选项*2
义项数量6 个用法

义项用法

1空间、场所的起点

用法
表示移动或范围开始的地点。
接续
场所名词 + から。

学校から家まで歩いて帰った。

がっこうからいえまであるいてかえった。

从学校步行回家了。

2时间的起点

用法
表示动作、状态或期间开始的时间。
接续
时间名词 + から。

会議は九時から始まる。

かいぎはくじからはじまる。

会议从九点开始。

3动作经过或通过的地点

用法
表示动作通过、进入或离开的通道、位置。
接续
场所名词 + から。

窓から冷たい風が入ってきた。

まどからつめたいかぜがはいってきた。

冷风从窗户吹了进来。

4动作、物品或信息的来源

用法
表示给予者、发送者、信息来源或动作的发出方。
接续
人物 / 组织名词 + から。

先生から本をもらった。

せんせいからほんをもらった。

从老师那里得到了一本书。

5因为……

用法
表示说话人判断、请求或结果的原因、理由。
接续
普通形 + から。名词和な形容词常用「だから」。

雨が降っているから、今日は出かけない。

あめがふっているから、きょうはでかけない。

因为正在下雨，今天不出门。

6……之后

用法
表示完成前项动作后，再进行后项动作。
接续
动词て形 + から。

ご飯を食べてから、薬を飲んだ。

ごはんをたべてから、くすりをのんだ。

吃完饭后吃了药。

整体提醒

名词 + から；普通形 + から；动词て形 + から。根据句子可表示空间、时间、来源、原因或动作先后。
