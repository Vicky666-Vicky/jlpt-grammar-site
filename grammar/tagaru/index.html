N1 A级文法篇

たがる

真题年份201706 / 201907 / 202212 / 202407
出现题型错误选项 / 正确选项*2
义项数量3 个用法

义项用法

1第三人称想要……

用法
根据他人的言行表现，描述其显露出来的愿望；不能直接断定对方内心。
接续
动词ます形去ます + たがる／たがっている。

弟は新しいゲームを買いたがっている。

おとうとはあたらしいゲームをかいたがっている。

弟弟想买新游戏。

2回顾过去的自己

用法
说话人把过去的自己作为观察对象，描述当时反复表现出的愿望。
接续
过去的第一人称 + 动词ます形去ます + たがった／たがっていた。

子供の頃の私は、何でも一人でやりたがった。

こどものころのわたしは、なんでもひとりでやりたがった。

小时候的我什么都想一个人做。

3转述他人对自己的观察

用法
引用或转述别人对说话人外在表现的判断，因此可以出现第一人称。
接续
他人の话／评价 + 第一人称 + 动词ます形去ます + たがる。

母によると、子供の頃の私はいつも外で遊びたがっていたそうだ。

ははによると、こどものころのわたしはいつもそとであそびたがっていたそうだ。

听母亲说，我小时候总想在外面玩。

整体提醒

动词ます形去ます + たがる；持续表现出的愿望常用「たがっている」。
