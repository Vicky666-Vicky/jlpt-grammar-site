N1 C级文法篇

に

真题年份201812
出现题型正确选项
义项数量10 个用法

义项用法

1存在或出现的场所

用法
标记人、事物存在、停留或出现的位置。
接续
场所名词 + に + いる／ある／泊まる／住む等。

机の上に本がある。

つくえのうえにほんがある。

桌子上有一本书。

2动作的到达点

用法
标记移动主体或被移动物最终到达、附着的位置。
接续
到达点名词 + に + 行く／着く／置く／貼る等。

九時に駅に着いた。

くじにえきについた。

九点到达了车站。

3具体时间

用法
标记动作或事件发生的明确时点。
接续
具体时间名词 + に + 动词。

毎朝七時に起きる。

まいあさしちじにおきる。

每天早上七点起床。

4移动行为的目的

用法
标记去、来、回等移动行为的目的。
接续
动作性名词／动词ます形词干 + に + 行く／来る／帰る。

駅前へ買い物に行く。

えきまえへかいものにいく。

去车站前购物。

5动作涉及的对象

用法
标记给予、传达、询问、会面等动作所指向的对象或接受者。
接续
对象名词 + に + 动词。

先生に質問した。

せんせいにしつもんした。

向老师提了问题。

6时间范围内的次数或数量

用法
标记计算频率、分配量时所依据的时间或单位范围。
接续
范围、单位名词 + に + 次数、数量。

この薬は一日に三回飲んでください。

このくすりはいちにちにさんかいのんでください。

这种药请一天服用三次。

7作为……、用作……

用法
标记某物被选择用于某种用途、身份或名目。
接续
用途、名目名词 + に + 选择、使用类动词。

旅行のお土産にお菓子を買った。

りょこうのおみやげにおかしをかった。

买了点心作为旅行伴手礼。

8原因或诱因

用法
标记引发情绪、身体反应或状态变化的原因。
接续
原因名词 + に + 感情、反应类动词。

突然の知らせに驚いた。

とつぜんのしらせにおどろいた。

因突如其来的消息而吃惊。

9比较、评价或适用的基准

用法
标记相似、远近、难易、效果等评价所依据或适用的对象。
接续
基准名词 + に + 近い／似る／難しい／効く等。

この家は駅に近い。

このいえはえきにちかい。

这座房子离车站很近。

10同类事物的组合或叠加

用法
在列举搭配中连接同类事物，表示“……加上……”或某种典型组合。
接续
名词A + に + 名词B。

朝食はパンに牛乳だった。

ちょうしょくはパンにぎゅうにゅうだった。

早餐是面包配牛奶。

整体提醒

名词 + に。具体作用需要结合名词语义和后面的动词、形容词判断。
