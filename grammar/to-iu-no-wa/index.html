N1 A级文法篇

というのは／というのも／というのが

真题年份201907 / 202107 / 202207
出现题型错误选项*2 / 句子理解
义项数量3 个用法

义项用法

1所谓……、……指的是

用法
提出需要解释或定义的名称、词语或事项，并在后文说明其内容。
接续
名词／普通形 + というのは、说明或定义。

「リモートワーク」というのは、会社以外の場所で働くことだ。

リモートワークというのは、かいしゃいがいのばしょではたらくことだ。

所谓远程办公，是指在公司以外的地方工作。

2这是因为……

用法
先陈述结论，再用「というのも」补充造成该结论的理由。
接续
结论。というのも、理由 + からだ／のだ。

今日は早く帰る。というのも、家に客が来るからだ。

きょうははやくかえる。というのも、いえにきゃくがくるからだ。

今天我要早点回去，因为家里要来客人。

3……这件事（作主语）

用法
用「というの」把前面的内容名词化，再用「が」把整件事标记为后项谓语的主语。
接续
普通形 + というのが + 评价、感情或说明。

彼が突然会社を辞めたというのが信じられない。

かれがとつぜんかいしゃをやめたというのがしんじられない。

我无法相信他突然辞职这件事。

整体提醒

话题 + というのは；句子。というのも、理由 + からだ／のだ；普通形 + というのが + 谓语。
