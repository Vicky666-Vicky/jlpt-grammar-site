ばかり

真题年份201507 / 201512 / 201607 / 201706 / 201907等 14 次
出现题型正确选项 / 错误选项 / 排序题 / 句子理解
义项数量7 个用法

义项用法

1只……

用法
表示范围集中在某一对象或事物上，相当于“只……”。
接续
名词 + ばかり。

彼は肉ばかり食べている。

かれは にくばかり たべている。

他只吃肉。

2总是……

用法
表示某动作反复进行，常含偏多、不满或责备的语气。
接续
动词て形 + ばかりいる。

弟は遊んでばかりいる。

おとうとは あそんでばかりいる。

弟弟总是在玩。

3刚刚……

用法
表示动作刚完成不久，实际时间长短不固定，重点是说话人心理上觉得近。
接续
动词た形 + ばかり。

彼は日本に着いたばかりです。

かれは にほんに ついたばかりです。

他刚到日本。

4不但……而且……

用法
在前项基础上追加后项，表示程度或范围进一步扩大。
接续
普通形 + ばかりか；名词 / な形容词词干 + であるばかりか。

彼は日本語ばかりか、英語も話せる。

かれは にほんごばかりか、えいごも はなせる。

他不但会日语，也会英语。

5只剩……要做

用法
表示其他准备已经完成，接下来只剩最后一个动作。
接续
あとは + 动词辞书形 + ばかりだ。

準備は終わった。あとは出発するばかりだ。

じゅんびは おわった。あとは しゅっぱつするばかりだ。

准备已经完成，只剩出发了。

6大约，左右

用法
接在数量词后，表示不精确的数量或时间估计。
接续
数量词 + ばかり。

駅まで三十分ばかりかかる。

えきまで さんじゅっぷんばかり かかる。

到车站大约要三十分钟。

7正因为……才导致

用法
表示由于某个原因导致不好的结果，语气中常有后悔、遗憾或责备。
接续
普通形 + ばかりに。名词和な形容词常用「であるばかりに」等形式。

油断したばかりに、失敗してしまった。

ゆだんしたばかりに、しっぱいしてしまった。

正因为大意，结果失败了。

整体提醒

根据义项不同接续不同。常见形式包括：名词 + ばかり、て形 + ばかり、た形 + ばかり、ばかりか、ばかりに。
