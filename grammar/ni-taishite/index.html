N1 B级文法篇

～に対して／～に対する

真题年份201507 / 201706 / 202312
出现题型错误选项 / 句子理解
义项数量3 个用法

义项用法

1对……、向……

用法
指出动作、态度、感情或评价所朝向的对象。
接续
对象名词 + に対して。

彼は上司に対して失礼な態度を取った。

かれはじょうしにたいしてしつれいなたいどをとった。

他对上司采取了无礼的态度。

2与……相反、相对于……

用法
并列两个不同对象或情况，突出二者的对照关系。
接续
普通形 + のに対して；な形容词 + なのに対して；名词 + であるのに対して。

兄が社交的なのに対して、弟は物静かだ。

あにがしゃこうてきなのにたいして、おとうとはものしずかだ。

哥哥善于社交，而弟弟很安静。

3每……、相对于……

用法
表示数量之间的对应比例。
接续
数量、单位名词 + に対して。

参加者十人に対して、先生が一人つく。

さんかしゃじゅうにんにたいして、せんせいがひとりつく。

每十名参加者配一位老师。

整体提醒

对象、比例：名词 + に対して；对比：动词／い形容词普通形 + のに対して，な形容词词干 + なのに対して，名词 + であるのに対して。
